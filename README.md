# Yordamchi Hamroh Hub v1.5

Zamonaviy va foydali AI yordamchi platformasi. Ushbu loyiha foydalanuvchilarga sog‘lom turmush, kundalik vazifalar, moliya nazorati va nafas mashqlari kabi funksiyalarni bitta dashboard orqali boshqarish imkonini beradi.

🌐 Live Demo: https://yordamch1.netlify.app/

---

# 📌 Loyiha Haqida

**Yordamchi Hamroh Hub** — bu foydalanuvchilarning kundalik hayotini osonlashtirish uchun yaratilgan aqlli dashboard platformasi.

Platformada quyidagi bo‘limlar mavjud:

- 💧 Suv balansi va gidratatsiya kuzatuvi
- ⚖️ BMI (Body Mass Index) kalkulyatori
- ✅ Vazifalar va taymer tizimi
- 💰 Aqlli moliya boshqaruvi
- 🫁 Nafas mashqlari
- 🤖 AI yordamchi funksiyalari

Dashboard minimalistik va zamonaviy UI/UX asosida ishlab chiqilgan.
